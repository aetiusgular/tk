# Lane R's contract checks (wave 4)

Scaffolded by integration w2 for lane R's (`tk acp`, `tk doctor`, `tk run -- <argv>`) (`plans/parallel_build_tk.md`, section 7a). `run.mjs` imports every `.mjs` file here; lanes add files, not lines. Each exports `checks`, an array of `{ id, title, harness, run }`; `run({ binPath, version, codexPath, claudePath })` returns `{ status: "pass" | "fail" | "info" | "skip", finding }`. Pass a CLI with `--cli <harness>=<path>` (the harness is the preset id, for example `--cli qwen-code=/tmp/cli/qwen/node_modules/.bin/qwen`). Fake model servers are in `../../lib/`: Anthropic Messages (`fakeMessages.mjs`), OpenAI Responses (`fakeResponses.mjs`), OpenAI chat completions (`fakeChat.mjs`), Gemini (`fakeGemini.mjs`). An agent that needs an account ships fixtures only and its row says "unverified at <version>" (call 8). The agents' hook contracts and fixtures: `contracts/hook-dialects.md`, `contracts/fixtures/hook-dialects/<agent>/`.
