# tk-connectors

A bundle (Claude Code and Codex plugin) of the entry skills for the connectors in the tk library. It installs skills only: no hooks, no commands, no MCP servers. The servers themselves come from the catalog entries the skills name, through `tk connect`.

The skill folders here are the source for the catalog's skill entries (`library/catalog/<skill>/skill.json` points at `skills/<skill>`), so one text serves both.
